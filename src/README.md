# Ghana at 70 UK website

Static site generated by one Python script, plus one Cloudflare Pages Function for forms. No framework. Hosted on Cloudflare Pages, domain ghanaat70uk.com.

## Run it on your computer

1. Python 3.12 or later: `python3 -m pip install -r src/requirements.txt`
2. `python3 src/serve.py`, then open http://localhost:8000
3. Forms work locally: each submission prints the record that would go to GoHighLevel.

`python3 src/build.py` on its own writes the finished site to `ghana-at-70/`. Never edit that folder, it is rebuilt every time.

## Go live

Follow `DEPLOY.md` at the top of the package. Fifteen minutes. Cloudflare Pages builds on every commit with `pip install -r src/requirements.txt && python3 src/build.py`, output `ghana-at-70`.

## Everyday updates, no developer needed

Edit on GitHub in the browser and commit. Cloudflare republishes in about a minute.

1. Announce a partner: `src/partners.json`, logo in `src/images/partners/`. Steps are at the top of the file. The build stops with a plain message if anything is missing.
2. Contact details, Ticket Tailor values, early bird on or off: `SITE_CONFIG` in `src/site.js`.
3. Prices and ticket names: the `T_GALA`, `T_DAY` and `T_SUN` lines in `src/build.py`, and the `DAYS` prices in `src/site.js`. Change both together.
4. New photo of people: add it in both sizes, run `python3 -m pip install opencv-python-headless numpy` once, then `python3 src/faces.py`, and commit `src/faces.json`.

## SITE_CONFIG in src/site.js

1. `contactEmail`, `contactPhone`: footer, contact page, error messages.
2. `ticketTailor`: `widgetScript`, `boxOffice`, four event IDs (`gala`, `ghanaday`, `sunday`, `weekend`) and their public links, plus `boxoffice`. While empty, Book now runs the built in booking form, which sends the booking to GoHighLevel. Once filled, Book now opens Ticket Tailor.
3. `earlyBird.on`: true while the Gala early bird is on sale, false when it closes. Never add a count to the page.
4. `left`, `booked`, `priorityCloses`: real numbers and dates only, otherwise leave empty.
5. `tracking`: GA4, Google Ads, Meta, TikTok, LinkedIn, Snapchat, Clarity IDs. Advertising tags load only after the visitor accepts cookies.

## What each form sends to GoHighLevel

Every form posts JSON to `/api/register`. The handler checks email and consent, drops bots through a hidden field, then forwards one record with `pipeline`, `stage` and `tags` already set.

1. `type`: guest, checkout, partner, pack, village, exhibitor, speaker, volunteer, press, contact, stay, ghana-travel, compete, sessions (Sunday talks and masterclasses interest).
2. Checkout adds: `day`, `quantity`, `unitPrice`, `value` (quantity x price), `basket`, `payBy` (card or bank), `giftFor`, `sitting`, `motherName`.
3. Every record carries UTM tags, click IDs, country, city and device.
4. Optional email copies: set `RESEND_API_KEY`, `FROM_EMAIL` and `NOTIFY_EMAIL` in the Cloudflare project variables.

## Launch checks

1. Every form arrives in GoHighLevel.
2. One booking per event shows the right sum.
3. Every page on a phone: no sideways scrolling.
4. Any missing address shows the 404 page.
5. Google Rich Results Test: the three event pages carry Event data, the questions page carries FAQ data.

## Rules that keep the site within UK consumer law

1. Every price shown is the full price. Nothing added at checkout.
2. Places left, guests booked or deadlines only when true.
3. Never restart a countdown or relabel a passed deadline.
4. Never publish a review a real guest did not write.
